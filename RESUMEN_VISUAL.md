## 🌟 Flujo de Interacción

```
1. INICIO
   ┌─────────────────────┐
   │   http://localhost  │
   │ Página Principal    │
   └──────────┬──────────┘
              │ Click "Iniciar Sesión"
              ↓

2. SELECCIÓN
   ┌─────────────────────┐
   │ /login              │
   │ Elegir: Admin o Eq. │
   └──────────┬──────────┘
              │
         ┌────┴────┐
         ↓         ↓

3. LOGIN ADMIN          LOGIN EQUIPO
   ┌─────────────────┐  ┌──────────────┐
   │ admin           │  │ prueba       │
   │ 1_Ch0col4t3...  │  │ 1234567      │
   └────────┬────────┘  └──────┬───────┘
            │                  │
            └────────┬─────────┘
                     ↓

4. DASHBOARD
   ┌─────────────────────────┐
   │ /dashboard?type=admin   │
   │ /dashboard?type=equipo  │
   └──────────┬──────────────┘
              │ Funciones por rol
              ├─ Admin: Monitoreo, Control
              └─ Equipo: Scanner QR, Puntos

5. ACCIONES
   ├─ [Escanear QR]
   ├─ [Ver Clasificación]
   ├─ [Monitoreo]
   └─ [Salir] → Volver a Inicio
```
