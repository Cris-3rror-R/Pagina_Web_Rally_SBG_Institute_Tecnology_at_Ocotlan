# Rally Competition Platform
Plataforma web full-stack desarrollada en Kiro IDE para gestionar en tiempo real un rally competitivo organizado en conjunto por las carreras de Ingeniería en Sistemas Computacionales y Ciberseguridad. La aplicación permite a los equipos participantes consultar su puntaje acumulado, identificar las estaciones pendientes y visualizar el podio en vivo, mientras que los organizadores (miembros del Core Team y la Leader) cuentan con un panel administrativo para controlar y actualizar las puntuaciones durante toda la jornada.

A nivel técnico, el frontend se construyó con Next.js, React, TypeScript y Tailwind CSS, tomando como referencia conceptual un diseño previo que fue reinterpretado y adaptado para esta edición con el apoyo de Kiro IDE. Para el backend se implementó una API en Python utilizando FastAPI, Uvicorn y SQLAlchemy, conectada a una base de datos en Supabase. Aunque inicialmente se contempló el despliegue en AWS Amplify, se migró exitosamente a Vercel para optimizar la puesta en producción.
